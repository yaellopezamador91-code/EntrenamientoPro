# EntrenamientoPro

Proyecto Android creado con Android Studio y Kotlin.

## Abrir el proyecto
1. Descarga o clona este repositorio.
2. Abre la carpeta en Android Studio.
3. Instala la versión del Android SDK que solicita Gradle y sincroniza el proyecto.

Este repositorio contiene el código fuente y los recursos del proyecto. Se excluyen configuraciones locales del SDK, carpetas generadas y los APK/AAB compilados. Guarda los archivos de publicación en un respaldo aparte. Las claves de firma y sus contraseñas deben conservarse en un lugar seguro, fuera de GitHub.
